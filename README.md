# 고교 수준 비교 (강남구 · 아산시)

학교별 국가 학업성취도 결과는 2017년 이후 공개되지 않으므로 아래 세 가지 공개 지표를 조합한다.

1. **교과별 성적 분포** — 학교알리미 (과목별 평균·표준편차·성취도 A~E 비율)
2. **졸업생 진로 현황** — 학교알리미 (4년제 진학률, 기타(재수 등) 비율)
3. **서울대·의대 합격 실적** — 언론 보도 (`data/admissions_2026.csv`)

## 진행 상태

| 단계 | 상태 |
|---|---|
| 수집 스크립트 (`scripts/schoolinfo.py`) | 작성 완료, 실제 API 미검증 |
| 1·2 데이터 수집·비교표 | 대기 — `schoolinfo.go.kr` 접속 허용 + API 키 필요 |
| 3 합격 실적 | 검색으로 확인된 일부만 기록, 원문 대조 필요 |

## 실행 순서

```bash
export SCHOOLINFO_API_KEY=...   # 학교알리미 > 알리미 소식 > OpenAPI 에서 발급
python scripts/schoolinfo.py probe --region 강남구          # 성취·진로 apiType 코드 확인
python scripts/schoolinfo.py fetch --region 강남구 --region 아산시 --types 0 <성취코드> <진로코드>
```

## 해석 시 주의

- 교과 평균은 학교마다 시험 난이도가 달라 단순 비교가 안 된다. 표준편차·A 비율과 함께 본다.
- 합격 실적은 졸업생 수, 재수생 포함 여부, 학교 유형(자사고·일반고)에 따라 달라진다.
